# Jeff 提词器 — 产品文档

## 一、产品定位

一款运行在 Windows 系统上的桌面提词器,帮助口播 / 视频创作者在录制时流畅读稿。
核心卖点:把写好的文案拖进去就能用,黑底白字自动滚动,当前句始终居中放大,一目了然。

## 二、核心功能(本期)

### 1. 拖拽导入文案
- 把文案文件**直接拖进窗口**即可加载,也支持点击「打开文件」按钮选择。
- 支持格式:**TXT(记事本)、Word(.docx)**。
- 兼容中文 Windows 记事本的 GBK 编码与 UTF-8 编码,拖进去不会乱码。

### 2. 提词显示(核心效果)
- 黑色背景、白色文字,整体**向上滚动**。
- **当前正在读的一句**:位于屏幕**正中间、字号最大、亮度最高(纯白)**。
- **即将读的下一句**:在下方、字号较小、颜色较浅(灰),**随滚动逐渐放大、变白,最终居中停留**。
- **已读过的句子**:向上移出、逐渐变暗消失。
- 缩放与明暗变化是连续平滑过渡,不是生硬跳行。

### 3. 速度调节
- 屏幕右侧有一个**加减按钮**的调节器。
- 点「＋」加快、点「−」放慢,实时显示当前速度。
- 速度单位:字/分钟。

### 4. 键盘控制
- `↑` 方向键 = 倒退到上一句(念错、想重来时用)。
- `↓` 方向键 = 跳到下一句。
- `空格` = 开始 / 暂停。
- `F11` = 全屏 / 退出全屏。

## 三、速度默认值(依据口播语速)

- 普通话口播正常语速约 **200–300 字/分钟**。
- 取中间偏舒适值 **250 字/分钟** 作为默认(居中值)。
- 可调范围 **80–500 字/分钟**,加减步进 10。

## 四、界面与交互细节

- 默认窗口 1280×800,可全屏;黑色背景、白色无衬线字体。
- 滚动方向:从下往上。
- 逐句动画为平滑过渡(缩放 + 透明度随位置连续变化)。
- 速度调节器固定在右侧,常驻细条样式。
- 未加载文件时,屏幕中央显示「拖入文件」提示。

## 五、技术方案

- Electron(已选定)。理由:文字缩放 + 渐变滚动的动画最丝滑,拖拽与 DOCX 解析生态成熟。
- 详细选型与实现说明见项目根目录 [CLAUDE.md](../CLAUDE.md)。

## 六、后续可扩展(本期不做,仅记录)

- 朗读计时(预估总时长)
- 导入 PDF、Markdown

## 七、验收标准

- [ ] 拖入一份 .txt 和一份 .docx 都能正确显示中文文案(不出现乱码)。
- [ ] 滚动中当前句居中且最大,下一句从灰渐变到白、从小说到大。
- [ ] 右侧加减能实时改变滚动速度,默认 250 字/分钟。
- [ ] 方向键 ↑↓ 能回退 / 下翻。
- [ ] 打包出可双击运行的 .exe。
